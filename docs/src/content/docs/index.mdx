Nixifest turns Kubernetes API schemas into typed Nix module options. Define resources in Nix, validate them during evaluation, and produce one multi-document YAML file for deployment or GitOps.

## What Nixifest provides

<CardGrid stagger>
	<Card title="Typed resources" icon="setting">
		Generated Kubernetes schemas turn API fields into discoverable Nix options.
	</Card>
	<Card title="Custom resources" icon="document">
		Bring your own CRDs and generate typed options during evaluation.
	</Card>
	<Card title="One YAML output" icon="document">
		Combine resources into one deterministic multi-document YAML file.
	</Card>
</CardGrid>
